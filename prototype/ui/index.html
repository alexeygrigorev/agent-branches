What each agent is doing

Are these changes safe together?

Every pair of agents is compared at their latest changes. “Safe” is only shown when the radar checked these two changes together at their latest versions and its combined test run actually collected and ran tests — otherwise the pair stays “unknown”, which means not safe, or “not checked”. Each agent’s own passing tests never make a pair safe.

Pushes that never arrived

The server was told about a push but could not record it. Until it can, that agent’s true latest change is unknown: every pair involving the agent stays “not checked” and is never shown safe.

Warnings sent

Conflicts found between agents, newest first. A warning “goes away” when one of the agents pushes a newer change.

What the labels mean

  • Conflict The radar tried these changes together and they clash. Someone needs to look.
  • Clean — tests ran The radar combined both changes at their latest versions, ran the combined tests, and found no clash.
  • Unknown — not safe The radar checked the pair but could not prove it safe. Do not rely on it.
  • Not checked These changes have not been compared at their latest versions yet — or the comparison found no clash but never ran combined tests.
